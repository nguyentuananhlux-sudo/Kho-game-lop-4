🚀 Đưa trò chơi lên GitHub Pages

  1. Mở kho mã nguồn GitHub của thầy/cô.
  2. Vào thư mục gốc, chọn Add file → Upload files.
  3. Kéo tệp games.json vừa tải lên, chọn ghi đè tệp cũ.
  4. Nhấn Commit changes và chờ GitHub Pages cập nhật.
  5. Chia sẻ link trang chủ ...github.io/.../index.html cho học sinh.

Lưu ý: GitHub Pages là trang tĩnh. Việc soạn trong trình duyệt không tự ghi ngược lên GitHub; cần tải games.json và tải lên kho mã nguồn.
